# Contributing

This is primarily a personal portfolio repository, but issues and pull requests that improve reproducibility, documentation, validation, accessibility, or analytical clarity are welcome.

Before submitting:
1. use synthetic or openly licensed data only;
2. do not add credentials, internal endpoints, or private datasets;
3. run `python scripts/validate_repository.py`;
4. update KPI documentation when calculation logic changes;
5. keep SQL, DAX, JavaScript, and expected outputs aligned.
