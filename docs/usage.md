# Usage

- Use the root HTML dashboard for an immediate browser demo.
- Replace the browser-selected CSV only with a file matching the documented public schema.
- Use `outputs/` as expected demonstration results for the checked-in synthetic dataset.
- Use SQL views as reusable analytical outputs for database-based workflows.
- Use Power BI measures and page specification to reproduce the dashboard in Power BI Desktop.
- When changing KPI logic, update `docs/kpi_definitions.md` first, then make the same change in SQL, DAX, JavaScript, and validation outputs.
