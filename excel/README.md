# Excel Deliverable

`Pharmacy_Assessment_Excel_Analysis.xlsx` is built from the repository's synthetic dataset and contains:

- `Clean_Data`
- `KPI_Summary`
- `Category_Analysis`
- `TGM_Analysis`
- `Zero_Sales_Risk`
- `Top_20_Performers`
- `Supplier_Analysis`
- `Key_Findings`
- `Charts_Dashboard`
- `Process_Documentation`

The workbook uses formulas for the clean-master derived columns and KPI/category calculations. It contains no proprietary source rows.
